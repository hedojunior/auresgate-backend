# AuResgate (Backend em iOS)

Backend desenvolvido em iOS, utilizando o framework Vapor, do protótipo de busca colaborativa de animais perdidos com
beacons Bluetooth Low Energy, desenvolvido como trabalho de conclusão de curso em Ciência da Computação na UNISINOS.

Frontend (App): https://github.com/hedojunior/auresgate-frontend </br>
Dados: https://github.com/hedojunior/auresgate-dados
